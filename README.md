##📊 Indian Ecosystem Analysis Dashboard

A Strategic Data Analysis Project Using CRISP-DM Framework
This project explores the Indian consumer and brand ecosystem through a robust data analysis pipeline and is designed to drive insightful business decisions, marketing strategy, and customer segmentation. Built using the CRISP-DM methodology, this analysis integrates survey data, perception analysis, and interactive visualization techniques.


##📘 Project Overview
This project evaluates how consumers interact with brands across industries in India. It offers a data-driven lens into:

Brand affinity and recall
Ecosystem perception mapping
Market positioning opportunities
Consumer behavior clustering

Driven by real-world survey data, the goal was to generate a comprehensive, interactive dashboard that could enable strategic brand and product decisions.

##🔍 Business Understanding
The business objectives were:

Understand consumer brand perceptions and usage patterns.
Identify white spaces in the Indian ecosystem for innovation or repositioning.
Enable stakeholders to interactively explore the consumer-brand matrix via filters and visuals.

##📊 Data Sources
Primary Survey Dataset: >8,000 survey responses.
Cleaned & Modeled Dataset: ~3,500 structured entries post preprocessing.
Additional external data (market share, category growth, etc.)

##🧠 Methodologies Used
| Technique                       | Purpose                                     |
| ------------------------------- | ------------------------------------------- |
| CRISP-DM Framework              | Standard data mining process                |
| Means-End Chain Analysis        | Understand consumer motives and values      |
| Top-of-Mind Recall Imaging      | Identify brand strength in memory           |
| Similarity-Dissimilarity Matrix | Cluster brands and consumers                |
| Data Cleaning and Normalization | Ensured quality and consistency of insights |
